# Pictures: Medhak Ki Chhalang

17 pictures. Make each one with an image tool, save it in images/ with the name shown (p01.jpg, p02.png, ...), then run `python rhyme.py render <slug>`. Any missing picture is drawn by code.

- Pictures can be any size; wide (16:9) is best. The video slowly moves across each one.
- A short clip made from a picture (image-to-video) also works: save it as p03.mp4.
- Same characters every time: first make ONE clear picture of each character below and keep it. In tools that take a reference picture, upload it with every prompt.
- Before a monetised upload, check the tool's terms allow commercial use on the plan you use, and never remove a tool's watermark. Song tools on a free plan (for example Suno's) are usually personal use only: the music stays ours.
- Change the scene sentence or the effect (rain, bubbles, sparkles, petals, stars, snow, none) in pictures.json, then run `python rhyme.py pictures <slug>` again: your edits are kept.
