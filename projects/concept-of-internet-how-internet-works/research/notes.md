# Research: Concept of Internet | How internet works

## Source: How Does the Internet Work - GeeksforGeeks
https://www.geeksforgeeks.org/blogs/how-does-the-internet-work/

- Internet connects over 4.5 billion users  
- 1.8 billion websites are connected via internet  
- Data is split into packets that travel through routers and switches  
- Round trip time for data is usually 20–200 ms  
- Every device has a unique IP address  
- IPv4 supports about 4.3 billion addresses  
- IPv6 was introduced to overcome IPv4’s limitations  
- TCP/IP handles packet addressing and routing  
- HTTP/HTTPS is used for web browsing  
- FTP is used for file transfers  
- SMTP/IMAP/POP3 are used for email communication  
- When you click an image, it loads in small packets  
- Each packet is usually around 1000–1500 bytes  
- Ethernet connects devices on the same local network  
- IP sends and receives packets between networks  
- TCP ensures packets arrive correctly and in order  
- HTTP formats data for websites and apps  
- UDP is used for faster, real-time data like videos or games  
- Your device sends a request to ISP when you type a URL  
- Browser converts website address into numeric IP address  
- Server sends website data in small packets  
- Browser reassembles packets to display full website  
- DSL uses telephone lines for broadband connection

## Source: How Does the Internet Work? - InfosecTrain
https://www.infosectrain.com/blog/how-does-the-internet-work

- Internet was first established in 1960s during Cold War  
- U.S. Department of Defense created it for communication during nuclear attack  
- ARPANET was the predecessor to modern Internet  
- By 1990s, Internet grew from academic tool to global phenomenon  
- IP address is unique number identifying devices on network (IPv4 or IPv6)  
- IP address acts like postal address ensuring data reaches right destination  
- Data packets are small segments of data sent over Internet  
- Each packet has metadata including source, destination, and sequence  
- DNS translates domain names into IP addresses (like phonebook)  
- ISP provides access to Internet and related services like website hosting

## Source: How does the Internet work? - Learn web development | MDN
https://developer.mozilla.org/en-US/docs/Learn_web_development/Howto/Web_mechanics/How_does_the_Internet_work

- Internet is the technical infrastructure that makes the Web possible  
- Internet began in the 1960s as a US-army-funded research project  
- It evolved into a public infrastructure in the 1980s with support from universities and companies  
- Internet connects computers together and ensures they stay connected despite changes  
- A simple network links two or more computers using physical cables (Ethernet) or wirelessly (Wi-Fi, Bluetooth)  
- Connecting ten computers requires 45 cables without a switch  
- A network switch helps by forwarding messages to the correct computer  
- Each computer has a unique MAC address for identification within a local network  
- MAC addresses are like fingerprints and can be assigned by manufacturers or software  
- Messages carry sender and recipient MAC addresses for routing  
- Switches learn where devices are located to forward messages efficiently  
- Multiple switches can be connected to form larger networks  
- Internet is a network of networks, allowing billions of computers to connect

## Source: What Is the Internet? Meaning, Working, and Types - Spiceworks
https://www.spiceworks.com/networking/what-is-the-internet/

- Internet is a global network of interconnected computers, servers, phones, and smart appliances  
- It uses TCP (Transmission Control Protocol) to enable fast exchange of information and files  
- Internet infrastructure includes optical fiber cables, copper wires, LAN, WAN, MAN  
- Wireless services like 4G, 5G, WiFi may still require physical cable installations  
- ICANN in the US controls internet and its technologies including IP addresses  
- ARPANET was the first internet concept developed by ARPA in 1969  
- ARPANET used packet switching to allow data to be broken into smaller parts (packets)  
- Packet switching doesn’t need a dedicated connection between users  
- Corporate packet networks were launched in the 1970s for efficient access to distant computers  
- Today, internet is a globally accessible public resource used by tens of millions  
- Private versions of internet exist for secure and regulated information exchange by large organizations

## Source: What is Internet - GeeksforGeeks
https://www.geeksforgeeks.org/computer-science-fundamentals/what-is-internet-definition-uses-working-advantages-and-disadvantages/

- Internet connects computers and devices worldwide  
- Enables communication, learning, and business  
- Supports digital services and cloud platforms  
- Uses standard communication protocols  
- ARPANET started in 1960s  
- First message sent via ARPANET in October 1969  
- Uses packet switching to break data into packets  
- Physical infrastructure includes optical fiber cables, copper wires, LAN/WAN/MAN  
- Mobile tech like 2G/3G/4G/Wi-Fi depends on physical networks  
- ICANN manages IP addresses, DNS, and global protocols  
- Internet works using client-server model  
- Client is a device like laptop or smartphone  
- Server stores websites and data  
- Client sends request through browser  
- Server identifies website via IP address  
- DNS converts domain name to IP address  
- Request routed to correct server  
- Server processes request and returns webpage  
- Domain name helps DNS find correct IP address  
- Mobile internet uses optical cables → towers → devices via electromagnetic waves  
- Wired internet uses fiber optics → router → Ethernet cables → computer  
- IP Address is unique identifier assigned by ISP  
- Example format: 192.154.3.29  
- Range of IP addresses: 0.0.0.0 to 255.255.255.255  
- WWW is collection of web pages accessed via URLs  
- Example URL: www.geeksforgeeks.org  
- WWW created by Timothy Berners-Lee in 1989 at CERN  
- W3C established for continued development of WWW  
- Internet is global system, WWW is part of it
